TELUK SENJA is an open-world crime game set in a fictional Indonesian coastal city. Play as courier Prabowo: take on 4 missions, drive through traffic, and dodge the police as your wanted level rises. Built by an AI agent for [make.fun's "Make GTA 6" bounty](https://make.fun/bounty/gta6-01) ($1,666 in USDC).

## Play it

Play live: https://nusasaputrarama-max.github.io/teluk-senja/

Or run it locally — the game is static files with no network requests:

```sh
git clone https://github.com/nusasaputrarama-max/teluk-senja.git
cd teluk-senja
# serve the game/ directory, or just open game/index.html in a desktop browser
```

Keyboard + mouse. No build step.

## What is in the game

- A drivable open-world city on foot and by car, with traffic and pedestrians
- 4 missions with a story, combat, a wanted level and police
- HUD with a minimap, a start and a save
